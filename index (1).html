AREA FEST COLLECTIVE

กลุ่มผู้บริหาร DELEF EVENT ดูแลทิศทางงานและมาตรฐานการผลิตทุกอีเวนต์

ดูพันธมิตรทั้งหมด

คำถามที่พบบ่อย

ซื้อบัตรได้ที่ไหน

ประกาศช่องทางจำหน่ายบัตรอย่างเป็นทางการผ่านเว็บไซต์และดิสคอร์ดของ DELEF EVENT ก่อนวันเปิดจำหน่าย

ผู้เข้างานต้องมีอายุเท่าไร

จำกัดอายุผู้เข้าร่วมงาน 16 ปีขึ้นไป เนื่องจากปัจจุบัน Roblox ซึ่งเป็นแพลตฟอร์มหลักที่ใช้ในการจัดงาน มีการกำหนดข้อจำกัดด้านอายุสำหรับประสบการณ์ (แมพ) บางประเภท ทั้งนี้ DELEF EVENT ยังมีทางเลือกอื่นสำหรับผู้ที่ไม่สามารถเข้าร่วมภายใน Roblox ได้ เช่น การรับชมการถ่ายทอดสดผ่านแพลตฟอร์มสตรีมมิ่ง TDL LIVE

จำเป็นต้องเข้าดิสคอร์ดเพื่อเข้าร่วมงานหรือไม่

ไม่จำเป็น ผู้เข้าร่วมสามารถเข้าร่วมงานผ่านช่องทางที่ DELEF EVENT กำหนดได้โดยตรง อย่างไรก็ตาม แนะนำให้เข้าดิสคอร์ดของเราเพื่อรับข่าวสาร ตารางงาน ประกาศสำคัญ และการอัปเดตต่าง ๆ ก่อนและระหว่างการจัดงาน

ต้องเข้าดิสคอร์ดเพื่อฟังเพลงหรือรับชมการแสดงหรือไม่

ไม่จำเป็น การรับชมการแสดงและการฟังเพลงภายในงานจะดำเนินการผ่านช่องทางที่ทีมงานประกาศอย่างเป็นทางการ ดิสคอร์ดมีไว้สำหรับการสื่อสาร ข่าวสาร และกิจกรรมต่าง ๆ ของชุมชนเป็นหลัก

ถ้าไม่มี Roblox สามารถเข้าร่วมงานได้หรือไม่

ขึ้นอยู่กับรูปแบบของแต่ละงาน หากงานนั้นรองรับการรับชมผ่านช่องทางอื่น DELEF EVENT จะประกาศรายละเอียดให้ทราบล่วงหน้า เช่น การถ่ายทอดสดผ่าน TDL LIVE

ถ้าเข้า Roblox ไม่ได้ สามารถดูงานได้หรือไม่

สำหรับงานที่มีการถ่ายทอดสด ผู้ที่ไม่สามารถเข้าร่วมภายใน Roblox สามารถรับชมผ่าน TDL LIVE หรือช่องทางสตรีมมิ่งที่ DELEF EVENT ประกาศอย่างเป็นทางการได้

ต้องมีบัตรเพื่อเข้าชมทุกงานหรือไม่

ไม่จำเป็นเสมอไป รูปแบบการเข้าชมและการจำหน่ายบัตรจะแตกต่างกันไปในแต่ละงาน โดย DELEF EVENT จะประกาศรายละเอียดของแต่ละงานอย่างเป็นทางการก่อนเริ่มจำหน่ายหรือเปิดให้เข้าร่วม

ซื้อบัตรแล้วต้องทำอย่างไรต่อ

หลังจากซื้อบัตรสำเร็จ กรุณาติดตามขั้นตอนการเข้าร่วมงานที่ประกาศโดย DELEF EVENT และตรวจสอบรายละเอียดเกี่ยวกับกำหนดการ ช่องทางเข้าร่วม และเงื่อนไขของงานนั้น ๆ

บัตรสามารถโอนให้ผู้อื่นได้หรือไม่

เงื่อนไขการโอนบัตรขึ้นอยู่กับข้อกำหนดของแต่ละงาน กรุณาตรวจสอบรายละเอียดที่ประกาศพร้อมกับข้อมูลการจำหน่ายบัตรก่อนทำการซื้อ

งานจัดขึ้นที่ไหน

สถานที่และช่องทางการจัดงานจะแตกต่างกันไปในแต่ละอีเวนต์ โดย DELEF EVENT จะระบุรายละเอียดของสถานที่จัดงาน หรือช่องทางการเข้าร่วมไว้ในหน้าอีเวนต์ของงานนั้น ๆ

สามารถเข้าร่วมงานผ่านโทรศัพท์มือถือได้หรือไม่

ขึ้นอยู่กับรูปแบบของงานและแพลตฟอร์มที่ใช้ในการจัดงาน โดยเฉพาะงานที่จัดผ่าน Roblox อุปกรณ์และข้อกำหนดในการเข้าร่วมอาจแตกต่างกันไปในแต่ละประสบการณ์

สามารถเข้าร่วมงานก่อนเวลาได้หรือไม่

เวลาเปิดให้เข้าร่วมจะแตกต่างกันไปในแต่ละงาน กรุณาตรวจสอบกำหนดการอย่างเป็นทางการของงานนั้น ๆ และติดตามประกาศจาก DELEF EVENT ก่อนเริ่มงาน

อยากเป็นสปอนเซอร์หรือพันธมิตรต้องทำอย่างไร

สามารถติดต่อ DELEF EVENT ผ่านดิสคอร์ดหรืออีเมลอย่างเป็นทางการของเรา เพื่อพูดคุยเกี่ยวกับรูปแบบความร่วมมือและรายละเอียดของโครงการ

อยากให้ DELEF EVENT จัดงานให้ ต้องติดต่อที่ไหน

สามารถติดต่อ DELEF EVENT ผ่านดิสคอร์ดหรืออีเมลอย่างเป็นทางการของเรา พร้อมแจ้งรายละเอียดเบื้องต้นเกี่ยวกับรูปแบบงาน วันเวลา และความต้องการในการจัดงาน

สามารถเสนอศิลปินหรือเพลงที่อยากให้มาในงานได้หรือไม่

สามารถเสนอความคิดเห็นหรือส่งคำแนะนำให้ทีมงานได้ผ่านช่องทางติดต่ออย่างเป็นทางการของ DELEF EVENT โดยทีมงานจะนำข้อมูลไปพิจารณาตามความเหมาะสมของแต่ละงาน

สามารถสมัครเป็นทีมงานหรือร่วมทำงานกับ DELEF EVENT ได้หรือไม่

สามารถติดตามประกาศรับสมัครทีมงานหรือโครงการที่เปิดรับบุคลากรผ่านช่องทางอย่างเป็นทางการของ DELEF EVENT โดยตำแหน่งและคุณสมบัติจะขึ้นอยู่กับความต้องการของแต่ละโครงการ
